# Прикладные системы и фреймворки искусственного интеллекта

Репозиторий содержит результаты лабораторных работ по дисциплине "Прикладные системы и фреймворки искусственного интеллекта" на задачах классификации и регрессии

Работу выполнил(а): Соловьева Н.С.

Группа: М8О-408Б-23

---

## Датасеты

| Задача | Датасет | Источник | Описание |
|--------|---------|----------|----------|
| **Классификация** | Breast Cancer Wisconsin (Diagnostic) | [UCI](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic) | 569 образцов, 30 признаков, бинарная классификация (malignant / benign) |
| **Регрессия** | Wine Quality (Red) | [UCI](https://archive.ics.uci.edu/dataset/186/wine+quality) | 1599 образцов красного вина, 11 физико-химических признаков, предсказание quality (0-10) |

### Обоснование выбора

- **Breast Cancer** - реальная задача медицинской диагностики. Модель помогает автоматически оценивать характер опухоли по характеристикам клеточных ядер
- **Wine Quality** - практическая задача контроля качества продукции в виноделии. Позволяет предсказывать экспертную оценку вина по лабораторным измерениям


---

## Основные результаты

### ЛР1 — KNN

В первой лабораторной работе исследовался алгоритм K-ближайших соседей (KNN) для решения задач классификации и регрессии. Были рассмотрены стандартная реализация из библиотеки `scikit-learn`, улучшенная модель с подбором гиперпараметров и собственная реализация алгоритма

#### Результаты классификации

Датасет: Breast Cancer Wisconsin (Diagnostic)

| Модель | Accuracy | F1-score | ROC-AUC |
|---|---:|---:|---:|
| sklearn baseline | 0.9123 | 0.9296 | 0.9559 |
| sklearn improved | 0.9737 | 0.9796 | 0.9884 |
| MyKNN (raw) | 0.9123 | 0.9296 | 0.9559 |
| MyKNN improved | 0.9737 | 0.9796 | 0.9884 |

#### Результаты регрессии

Датасет: Wine Quality (Red)

| Модель | MAE | RMSE | R^2 |
|---|---:|---:|---:|
| sklearn baseline | 0.5788 | 0.7294 | 0.1859 |
| sklearn improved | 0.3932 | 0.5494 | 0.5380 |
| MyKNN (raw) | 0.5788 | 0.7294 | 0.1859 |
| MyKNN improved | 0.3932 | 0.5494 | 0.5380 |

#### Подбор гиперпараметров

Для улучшенных моделей использовался `GridSearchCV` с пятиблочной кросс-валидацией и предварительным масштабированием признаков с помощью `StandardScaler`

Получены следующие оптимальные параметры:

- **Классификация:** `n_neighbors = 7`, `p = 2`, `weights = uniform`
- **Регрессия:** `n_neighbors = 11`, `p = 1`, `weights = distance`

Масштабирование выполнялось внутри конвейера `Pipeline`, что позволяет избежать утечки данных между обучающими и проверочными фолдами при кросс-валидации

#### Выводы по ЛР1

В ходе экспериментов установлено, что масштабирование признаков и подбор гиперпараметров существенно улучшают качество KNN.

Для задачи классификации Accuracy увеличилась с 0.9123 до 0.9737, а ROC-AUC — с 0.9559 до 0.9884.

Для задачи регрессии MAE снизилась с 0.5788 до 0.3932, RMSE — с 0.7294 до 0.5494, а коэффициент детерминации R^2 увеличился с 0.1859 до 0.5380.

Собственная реализация MyKNN с масштабированием и подобранными гиперпараметрами показала такие же результаты на тестовой выборке, как и улучшенная реализация `scikit-learn`
